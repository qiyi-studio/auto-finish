# 会员离开自动完成（Chrome / Edge 扩充功能）

客服后台中，当会员跳出、离开对话时（画面出现「xxx 已于 2026/09/23 17:36:30 离开对话」），自动帮你按下右上角的「✓ 完成」按钮。

## 功能

- 侦测对话中出现「离开对话」提示
- 自动点击「完成」按钮，若跳出确认视窗会再自动点「确定 / 确认」
- **防呆**：只有离开的会员帐号与目前对话标题上的帐号相同时才会点，不会误结束别人的对话
- **背景也会运作**：客服页面不在前景（切到别的分页、别的视窗或最小化）时，一样会自动结案
- 关键字、按钮文字、延迟时间、启用网址都可在设定视窗修改

## 安装

1. 下载或 clone 本仓库到电脑，放在固定位置（不要删除或移动）
2. Chrome 网址列输入 `chrome://extensions`（Edge 为 `edge://extensions`）
3. 打开右上角 **开发人员模式**
4. 点 **载入未封装项目**，选择本仓库文件夹（含 `manifest.json` 的那一层）
5. 重新整理客服页面即可

## 背景运作注意事项

- 客服页面的**分页不能关掉**，可以切走或最小化
- 扩充功能会自动要求浏览器不要释放这个分页
- 建议再到 `chrome://settings/performance`，在「一律让这些网站保持运作状态」加入客服后台网址，避免被节能模式冻结
- 电脑不能进入睡眠

## 设定

点工具列上的扩充功能图示：

| 项目 | 预设值 | 说明 |
|---|---|---|
| 启用自动完成 | 开 | 总开关 |
| 网址包含 | （空白） | 只在网址含此文字的网站运作，建议填客服后台网址 |
| 离开关键字 | `离开对话` | 一行一个 |
| 「完成」按钮文字 | `完成` | 一行一个，会自动忽略 ✓ 图示与空白 |
| 确认视窗按钮文字 | `确定`、`确认` | 一行一个 |
| 延迟毫秒 | `0` | 侦测到离开后立即按下；若偶尔按不到可改成 300～500 |

修改后按「保存」，并重新整理客服页面。

## 疑难排解

在客服页面按 F12 → Console，查看 `[自动完成]` 开头的讯息：

- `已启用`：扩充功能正在运作
- `侦测到离开：…` → `点击：完成`：成功
- `找不到「完成」按钮`：请到设定修改按钮文字
- `…不是目前对话，略过`：离开的是别的会员，属正常防呆

## 文件

- `manifest.json`：扩充功能设定（Manifest V3）
- `content.js`：侦测与自动点击逻辑
- `background.js`：让客服分页在背景保持运作
- `popup.html` / `popup.js`：设定视窗
